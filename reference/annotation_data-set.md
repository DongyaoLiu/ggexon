# Coerce and assign annotation data

Coerce and assign annotation data

## Usage

``` r
annotation_data(x) <- value
```

## Arguments

- x:

  A `SynIndividual` object.

- value:

  A
  [`GenomicRanges::GRanges`](https://rdrr.io/pkg/GenomicRanges/man/GRanges-class.html)
  object or `NULL`.

## Value

The updated `SynIndividual` object.
