# Store a ggexon panel layout on a `SynSpecies` object

Store a ggexon panel layout on a `SynSpecies` object

## Usage

``` r
species_layout(x) <- value
```

## Arguments

- x:

  A `SynSpecies` object.

- value:

  A `SynLayout`, layout `data.frame`, or `NULL`.

## Value

The updated `SynSpecies` object.
