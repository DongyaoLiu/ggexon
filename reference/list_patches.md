# List annotation patches

List annotation patches

## Usage

``` r
list_patches(x, annotation = NULL)
```

## Arguments

- x:

  A `SynFeatureAnnotation` or `SynIndividual` object.

- annotation:

  Optional feature-annotation layer name when `x` is a `SynIndividual`.

## Value

A named list of `SynAnnotationPatch` objects.
