# Geom implementation for amino-acid variant lollipops

Internal ggproto used by
[`geom_aa_variant()`](https://dongyaoliu.github.io/ggexon/reference/geom_aa_variant.md).
Draws each variant as a head (point) raised above the exon row on a
short stem, so amino-acid variants can be read directly against the
exon/intron model.

## Usage

``` r
GeomAaVariant
```

## Format

An object of class `GeomAaVariant` (inherits from `Geom`, `ggproto`,
`gg`) of length 12.
