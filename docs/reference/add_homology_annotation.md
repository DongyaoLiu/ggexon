# Add or replace a HomologyAnnotation on a SynSpecies

Add or replace a HomologyAnnotation on a SynSpecies

## Usage

``` r
add_homology_annotation(x, homology)
```

## Arguments

- x:

  A `SynSpecies` object.

- homology:

  A `HomologyAnnotation` object.

## Value

An updated `SynSpecies` object.
