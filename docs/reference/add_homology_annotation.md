# Add or replace a HomologyAnnotation on a SynSpecies

Add or replace a HomologyAnnotation on a SynSpecies

## Usage

``` r
add_homology_annotation(x, homology)

# S4 method for class 'SynSpecies,HomologyAnnotation'
add_homology_annotation(x, homology)

# S4 method for class 'SynSpecies,ANY'
add_homology_annotation(x, homology)

# S4 method for class 'ANY,HomologyAnnotation'
add_homology_annotation(x, homology)

# S4 method for class 'ANY,ANY'
add_homology_annotation(x, homology)
```

## Arguments

- x:

  A `SynSpecies` object.

- homology:

  A `HomologyAnnotation` object.

## Value

An updated `SynSpecies` object.
