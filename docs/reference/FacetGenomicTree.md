# ggproto backend for `facet_genomictree()`

ggproto backend for
[`facet_genomictree()`](https://dongyaoliu.github.io/ggexon/reference/facet_genomictree.md)

## Usage

``` r
FacetGenomicTree
```

## Format

An object of class `FacetGenomicTree` (inherits from `FacetGenomics`,
`FacetWrap`, `Facet`, `ggproto`, `gg`) of length 2.
