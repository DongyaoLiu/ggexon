# The major ggexon object

The major ggexon object

## Usage

``` r
class_ggexon(
  data = waiver(),
  ...,
  layers = list(),
  cross_panel_annotations = list(),
  genomic_tree = NULL,
  genomic_x_scale = NULL,
  strip_scale = NULL,
  scales = NULL,
  guides = NULL,
  mapping = aes(),
  theme = NULL,
  coordinates = coord_cartesian_genomic(default = TRUE),
  facet = facet_null(),
  layout = NULL,
  labels = labs(),
  plot_env = parent.frame()
)
```
