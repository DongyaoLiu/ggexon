# Add SynIndividual objects to a SynSpecies object

Add SynIndividual objects to a SynSpecies object

## Usage

``` r
add_individual(x, individual, ...)

# S4 method for class 'SynSpecies,SynIndividual'
add_individual(x, individual, ...)

# S4 method for class 'SynSpecies,ANY'
add_individual(x, individual, ...)

# S4 method for class 'ANY,SynIndividual'
add_individual(x, individual, ...)

# S4 method for class 'ANY,ANY'
add_individual(x, individual, ...)
```

## Arguments

- x:

  A `SynSpecies` object.

- individual:

  A `SynIndividual` object.

- ...:

  Additional `SynIndividual` objects to add.

## Value

An updated `SynSpecies` object.
