# Add a locus set to a SynSpecies object

Add a locus set to a SynSpecies object

## Usage

``` r
add_locus_set(x, locus_set)

# S4 method for class 'SynSpecies,SynLocusSet'
add_locus_set(x, locus_set)

# S4 method for class 'SynSpecies,ANY'
add_locus_set(x, locus_set)

# S4 method for class 'ANY,SynLocusSet'
add_locus_set(x, locus_set)

# S4 method for class 'ANY,ANY'
add_locus_set(x, locus_set)
```

## Arguments

- x:

  A `SynSpecies` object.

- locus_set:

  A `SynLocusSet` object.

## Value

An updated `SynSpecies` object.
