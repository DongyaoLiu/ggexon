# Construct a locus-window set

Construct a locus-window set

## Usage

``` r
SynLocusSet(name, loci, source_file = "<locus_set>", metadata = list())
```

## Arguments

- name:

  Short unique locus-set name.

- loci:

  Data frame with one row per comparable window.

- source_file:

  Optional source label.

- metadata:

  Optional metadata list.

## Value

A `SynLocusSet` object.
