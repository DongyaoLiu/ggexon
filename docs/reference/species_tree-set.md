# Store tree objects on a `SynSpecies`

Store tree objects on a `SynSpecies`

## Usage

``` r
species_tree(x) <- value

# S4 method for class 'SynSpecies'
species_tree(x) <- value

species_tree_plot(x) <- value

# S4 method for class 'SynSpecies'
species_tree_plot(x) <- value
```

## Arguments

- x:

  A `SynSpecies` object.

- value:

  A tree object, a rectangular `ggtree` plot, or `NULL`.

## Value

The updated `SynSpecies` object.
