# Shared MHC head rows

User request: matching MHC gene heads should occupy consistent rows across haplotypes, preserving native genomic anchors and a common bp scale. Clarify that the partner haplotypes have curated MHC spans, not V(D)J genes, and their unavailable general context annotation is not biological absence.

Add an optional numeric `head_row` aesthetic to geom_gene_lollipop in column mode. Assign every source gene key to one of six shared physical rows, numbered bottom to top, regardless of its functional/pseudogene status. Use the existing CHM13 six-row layout for source keys represented there. Place ape-only Ap, OKO, unspecified DRB and DRB3 in explicit layout slots, keeping their original source identities distinct. Shared row positions are display metadata and do not establish orthology between different keys.

Consecutive display-ordered genes can share a head column only while their assigned row numbers strictly descend. A dynamic program explores every such contiguous partition and selects the minimum feasible column count under panel/gutter bounds and displacement limits. A duplicate row or an increase starts another column, preserving source genomic order, distinct copies and noncrossing gutter leaders. Gutters use only the number of occupied lanes. Empty row slots remain blank. The same source gene key always uses the same row, and duplicated copies remain separate heads on that row with independent native anchors. Keep head width/font, 25 mm displacement bound, source colors/status and native context genes. Provide enough physical height for all six rows on every haplotype; do not shrink labels or alter anchors.

Supply and export the full explicit source-key-to-row template. Verify rows by key on both PDF/PNG, physical row offsets across panels, unchanged coordinates/bp geometry, all 285 genes, source status, nonoverlap and leader/head nonintersection/crossings. Clarify strip labels as context annotated / context unavailable, preserving provenance for the existing seven context-annotated haplotypes and six curated-only partners. No missing gene models are copied between haplotypes.
