# IG/TR source tables

`genes.tsv`: repository plot annotations, track_id (HSA1/PPA1/2/GGO1/2/PAB1/2/PPY1/2), species, haplotype, locus, facet (`TRA/TRD` combines both), gene_type V/D/J, source_label, contig, genomic_pos_source, locus_pos_source, start/end (1-based closed locus-relative), display_start/end (same, reversed when config orientation=-1), strand, productive (True/False/unknown), is_species_specific, sequence_length, sequence_verified, locus_pos_corrected, source_row, source_file. Source LocusPos is 0-based; loci FASTAs validate sequence locations. When genomic Pos identifies a repeated copy that source LocusPos incorrectly places at its first sequence occurrence, a verified Pos +/- 1 candidate repairs the locus offset.

`loci.tsv`: track_id, species, haplotype, locus, facet, length, display_orientation, track_order, source_track, contig, genomic_start0/end0 (FASTA slice bounds), fasta_length, source_file. Display reversals apply consistently to all layers.

`alignments.tsv`: locus, facet, track1, track2, identity, source_file/row, start1/end1/start2/end2 (source 1-based closed locus-relative aligned endpoints; may descend), display_start1/end1/display_start2/end2 (orientation transformed). These are the exact public long non-overlapping alignment blocks; source pairs follow PPA1,PPA2,HSA1,GGO1,GGO2,PAB1,PAB2,PPY1,PPY2. A human-first renderer must retain nonadjacent PPA2-HSA1 and HSA1-GGO1 pairs, or use source track order.

`sv_blocks.tsv`: track_id, locus, facet, start/end and display_start/end, color, source_file, annotation. Native 0-based half-open source Start/End converted to 1-based closed. Source calls them structural variation blocks; no support for calling every block a segmental duplication.

`counts.tsv`: source row counts by track/locus/V-D-J; unique intervals additionally shown because IGHD source can contain opposing strand entries at the same interval. Species-specific and productive true/false/unknown counts reflect source fields, not invented status.

`supplementary_gene_annotations.tsv`: retained Supplementary Data1 columns without coordinate conversion. Final paper annotation has 3346 ape records; repo plot annotation is a separate older source and may have different counts. `functional` is Functional/ORF (not binary pseudogene). Gene_start/gene_end are paper's final boundaries. Family-level shared versus species-specific flag is unavailable in the supplement, but repository per-gene IsSpeciesSpecific is available.

`paper_genes.tsv` is the preferred final-paper gene table: 3346 Supplementary Data1 ape rows + 383 explicitly distinguished human repository plot rows + 9 additional nonoverlapping human delta BED rows. Contains track_id/species/haplotype/locus/facet, gene_family (e.g. TRAV/DV, TRDJ), gene_type (V/D/J/unknown), contig, genomic_start/end (1-based closed paper gene_start/gene_end; human verified repository-derived coding sequence extent), start/end and display_start/end (1-based closed locus-relative), strand, functional (Functional/ORF for supplement; unknown for human because Productive alone does not establish the paper status), is_species_specific (True/False/unknown), specificity_evidence, source_id/file, annotation_source, within_locus. The paper final annotated gene span and old repository coding segment span can differ. Raw Supplementary Data1 preserves both digger and IgDetective boundaries for audit. Species specificity is transferred only where repository IgDetective type and position agree within one base; 578 rows remain unknown. Do not relabel unknown as shared. All 3738 rows lie within their source config locus bounds. The one unclassified bonobo paternal IGK record has an empty source gene_type and is preserved as unknown.

`paper_counts.tsv`: exact rows by track/locus/gene_family, with Functional/ORF/unknown breakdown. TRA/TRD has one combined genomic facet and is counted once. These are source rows, not averages or numbers adjusted to match paper prose.

## Known upstream inconsistencies

- Human TRG FASTA is 78960 bp but config display span is 170175 bp; nine human TRG CSV features extend beyond the public truncated FASTA and cannot be sequence-validated. Their published LocusPos and config are retained, clearly marked sequence_verified=False in genes.tsv.
- One bonobo maternal IGL feature has LocusPos=2037069 at the edge of a 2057070-bp locus but its source gene sequence fails exact validation. Retained with sequence_verified=False.
- Of 3349 source plot CSV rows, 3339 sequence-validate; 326 source LocusPos values were corrected by exact sequence verification at the genomic Pos +/-1 candidate. The original fields are always preserved.
- The source plotting code uses fixed-width boxes, while prepared genes.tsv uses sequence length. Final supplementary annotations instead use its stated final gene_start/end.
- Public IsSpeciesSpecific flags annotate genes, not a fully inferred gene-family phylogeny. False means the source did not call that gene species-specific; no new family conservation claim is inferred.
- SV-block color is preserved as the author's categorical color; the repository does not publish a textual meaning for each color. Label these as source SV blocks, not certified segmental duplications.
- Pairwise block coordinates are treated as 1-based inclusive, supported by the source plotting script subtracting one before drawing. SV intervals follow the source raw 0-based plotting positions; preserved raw files allow re-interpretation.

Human delta augmentation: the supplied NCBI BED has TRDV1-3, TRDD1-3, TRDJ1-4 and five shared TRAV/DV intervals. TRDV1 and all five shared V records already overlap repository plot coding-region records, so those existing records are reclassified by family without adding duplicates. Missing TRDV2/3, TRDD1-3 and TRDJ1-4 add nine records with distinct `annotation_source=repository-supplied NCBI BED gene interval`, exact source_id gene symbol, unknown functional/specificity status. They use BED full-gene interval extents, which differ from the plotting CSV coding-region extents. No ape TRDD annotation is inferred from the absence of TRDD rows in Supplementary Data1.
